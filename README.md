# Общее меню кофейни

Мы вместе делаем меню кофейни. Каждый добавляет **одно своё блюдо** с ценой, а программа собирает блюда всей группы в одну таблицу.

Чтобы никто никому не мешал, у каждого свой файл и своя ветка.

## Задание

Ниже вместо `<логин>` везде подставьте **ваш логин на GitHub** латиницей, без пробелов. Он должен быть одинаков в названии ветки и файла.

### 1. Скачайте проект

```bash
git clone https://github.com/iivanova-ivanna/cafe-menu.git
cd cafe-menu
```

Если git просит представиться (один раз на компьютере):

```bash
git config --global user.name "Ваше имя"
git config --global user.email "ваша@почта"
```

### 2. Создайте свою ветку

```bash
git switch -c dish/<логин>
```

Проверьте: `git branch` показывает `* dish/<логин>`. Работать нужно **только в своей ветке**, не в `main`.

### 3. Создайте файл своего блюда

Скопируйте шаблон под своим именем:

```bash
copy menu\_template.json menu\<логин>.json
```

Откройте `menu/<логин>.json` и поменяйте значения. **Сохраните файл** (Ctrl+S).

```json
{
  "name": "Бургер Миши",
  "price": 7.5,
  "author": "Миша"
}
```

Правила:
- текст (`name`, `author`) пишется в кавычках;
- цена (`price`) пишется **без кавычек** и **через точку**: `7.5`, а не `7,5` и не `"7.5"`;
- цена должна быть больше 0 и не больше 100;
- после каждой строки, кроме последней, стоит запятая.

### 4. Проверьте, что программа видит ваше блюдо

```bash
python main.py --text
```

Ваше блюдо должно появиться в списке. Если внизу есть строка с вашим файлом и красным `!`, прочитайте, что в ней написано, исправьте файл и запустите проверку ещё раз.

### 5. Сохраните изменения и отправьте

```bash
git add menu/<логин>.json
git commit -m "Add dish: <название блюда>"
git push -u origin dish/<логин>
```

### 6. Откройте Pull Request

На странице репозитория на GitHub нажмите жёлтую кнопку **Compare & pull request**, затем **Create pull request**. Дальше дождитесь, пока ваш Pull Request сольют с `main`.

### 7. Посмотрите общий результат

Когда преподаватель сказал, что всё слито:

```bash
git switch main
git pull
python main.py
```

В таблице должны быть блюда всей группы и ваше тоже.

## Задание для быстрых

Не выходя из своей ветки, добавьте в свой файл поле `category` (например `"Напитки"`, `"Десерты"`, `"Горячее"`). Не забудьте поставить запятую после предыдущей строки.

```bash
python main.py --text
git add menu/<логин>.json
git commit -m "Add category to my dish"
git push
```

Ваш Pull Request обновится автоматически. Если его уже слили, откройте новый.

## Если что-то не получилось

| Что случилось | Что делать |
|---|---|
| `git push` пишет `Permission denied` или `403` | Вас ещё не добавили в репозиторий. Примите приглашение в почте или на GitHub и позовите преподавателя |
| Ошибка в строке JSON | Проверьте запятые и кавычки. Попробуйте сравнить с `menu/example.json` |
| Вы случайно сделали коммит в `main` | Позовите преподавателя. Это легко исправить |
| `git status` показывает много лишнего | Вы не в той папке. Проверьте, что вы в папке `cafe-menu` |
